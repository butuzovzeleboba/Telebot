# A Telegram bot for movie recommendations
A parser that works with various web resources collects information about movies, cartoons, series, and anime, structuring it into separate dataframes. This data is then passed to a Telegram bot, which, based on the user's preferred genre, offers a random selection for a pleasant evening of viewing.
#  TG-бот для рекомендаций фильмов
Парсер, работающий с различными веб-ресурсами, собирает информацию о фильмах, мультфильмах, сериалах и аниме, структурируя ее в отдельные датафреймы. Эти данные затем передаются в Telegram-бота, который, основываясь на предпочтительном жанре пользователя, предлагает случайный выбор для приятного вечернего просмотра.
